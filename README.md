## Kurzablauf

1. Dynamo Player starten und `run=True` setzen.
2. Elemente in der gewuenschten Reihenfolge auswaehlen.
3. Parameter im Dialog auswaehlen und optional Reihenfolge, Parameternamen, Farbe und Mindestabstand einstellen.
4. Zwei Punkte fuer Startposition und Richtung setzen.
5. Tags werden erzeugt und in `TH_Beschriftungstext` beschriftet.
